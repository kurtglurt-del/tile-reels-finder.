# Tile Reels Finder — Web MVP

## Запуск
Самый простой вариант — разместить содержимое папки на статическом HTTPS-хостинге. Для установки как PWA нужен HTTPS (или localhost при разработке). Можно использовать GitHub Pages, Netlify или Cloudflare Pages.

Для локального просмотра можно открыть `index.html` в браузере, но установка как приложение и Service Worker требуют HTTPS/localhost.

## Возможности
- Быстрые запросы по укладке керамогранита, крупному формату, запилу 45°, ванным и полам.
- Открытие тематического поиска в Instagram, Google или YouTube.
- Локальная библиотека ссылок и заметок с удалением дублей.
- Адаптивный интерфейс для Android и настольного браузера.
- Базовый офлайн-кеш для размещённой HTTPS-версии.

## Ограничения
Эта версия не собирает автоматически все Instagram Reels. Она запускает поиск во внешнем сервисе и сохраняет добавленные пользователем ссылки. Не обходит авторизацию, не скачивает видео и не извлекает скрытые данные.

Для автоматизированного поиска нужен отдельный backend и источник, использование которого разрешено его условиями. Instagram API не является универсальным поиском по всем роликам. Любые будущие API-токены нельзя помещать в публичный JavaScript — их следует хранить на сервере.
